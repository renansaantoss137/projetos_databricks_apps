1. Baixar Planilha Atual (.xlsx)

Baixe a versão mais recente no modelo oficial Base - VCM.xlsx (25 colunas oficiais com abas e dados preservados).

  • 1 Clique no botão abaixo para baixar o arquivo oficial Base - VCM.xlsx.
  • 2 Abra a planilha no Microsoft Excel instalado no seu computador.
  • 3 Atualize ou adicione seus números na aba Base de VCM mantendo as colunas oficiais.
  • 4 Salve o arquivo no seu computador quando terminar.

2. Importar Planilha Atualizada

Envie sua planilha preenchida para validação instantânea e atualização direta no Databricks.

Obrigatório: Salvar planilha com rótulo PÚBLICO
Para que o sistema consiga ler o arquivo, a planilha deve ser salva no Microsoft Excel com sensibilidade Público. Arquivos salvos como Interno, Confidencial ou Restrito são criptografados pelo Microsoft 365 e impedem a leitura.
🔐
Planilha Bloqueada: Rótulo Não é "Público"
Base - VCM.xlsx
Esta planilha não pôde ser processada porque está protegida por criptografia da Microsoft. Esse bloqueio acontece quando o arquivo é salvo no Excel com um rótulo de confidencialidade diferente de PÚBLICO (por exemplo, Interno, Confidencial ou Restrito).
Como resolver passo a passo no Excel:
  1. Abra o arquivo no Microsoft Excel.
  2. Na barra superior do Excel, clique no botão Sensibilidade (ou Confidencialidade / Rótulo).
  3. Selecione a opção PÚBLICO (ou Sem Restrição).
  4. Salve o arquivo (Ctrl + B ou Ctrl + S) e feche o Excel.
  5. Arraste ou selecione a planilha salva novamente abaixo.
